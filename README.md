# Рататуй (Удаленное управление)

Система управления поваром Лингвини с помощью крысы Реми.

## Диаграммы

| Диаграмма | Описание | Файл |
|-----------|----------|------|
| Use Case  | Варианты использования системы (приготовить суп, управлять поваром, пройти проверку критика) | [doc/use_case.puml](doc/use_case.puml) |
| Class     | Диаграмма классов (Remy, Linguini, Dish) | [doc/class.puml](doc/class.puml) |
| Activity  | Алгоритм: Реми дергает за волосы -> Лингвини двигает рукой -> нарезка овощей | [doc/activity.puml](doc/activity.puml) |
| Sequence  | Пошаговое взаимодействие: Remy -> Linguini (pullHair) -> Dish | [doc/sequence.puml](doc/sequence.puml) |
| State     | Жизненный цикл повара: Idle -> Controlled -> Panic | [doc/state.puml](doc/state.puml) |

## Как открыть диаграммы

1. Перейдите по ссылке на любой `.puml` файл из таблицы выше
2. GitHub покажет код диаграммы
3. Скопируйте код и вставьте в [онлайн-редактор PlantUML](https://www.plantuml.com/plantuml/uml/)
4. Или установите [PlantUML локально](https://plantuml.com/download)
