# Рататуй - Удаленное управление 🐭👨‍🍳

Проект по UML-моделированию системы управления поваром Лингвини крысой Реми.

## Диаграммы

- **Use Case Diagram** - варианты использования
- **Class Diagram** - структура классов
- **Sequence Diagram** - взаимодействие объектов
- **Activity Diagram** - процесс приготовления
- **State Diagram** - состояния повара

## Как просмотреть диаграммы

1. Установите PlantUML или используйте [онлайн-редактор](https://www.plantuml.com/plantuml/uml/)
2. Откройте любой .puml файл
3. Скопируйте код в онлайн-редактор или сгенерируйте изображение
